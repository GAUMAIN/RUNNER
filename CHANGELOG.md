## Versioning Policy

- `0.x.y` — pre-release / pre-launch development
- `1.0.0` — public launch
- `MAJOR.MINOR.PATCH`
  - **MAJOR** — save format breaks or non-backward-compatible content changes
  - **MINOR** — new systems / zones / features
  - **PATCH** — bug fixes, balance tweaks, polish
